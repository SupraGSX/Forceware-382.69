Forceware 382.69 - custom NVIDIA Windows XP 32-bit driver

Launch Forceware 382.69.exe, then follow the normal NVIDIA installer and restart.
Alternatively, extract the package and run setup.exe.
This is a modified, unsigned 368.81-based package, not an official NVIDIA 382.69 release.

Includes Pascal initialization/3D, DisplayPort HBR3 and color-depth fallback,
HDMI identification/SCDC and scoped clock-limit fixes, and integrated Control
Panel Customize and topology/EDID support. No separate add-on is required.

See Documentation/Forceware-382.69.md for supported INF additions and validation.
